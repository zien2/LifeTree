## 📱 页面功能详解

### 🎯 注册页面 (http://localhost:3000/register)

#### 功能特性
- ✅ **完整的表单验证**
  - 邮箱格式验证
  - 密码强度验证（8+字符，大小写+数字）
  - 密码确认匹配验证
  - 昵称长度验证（可选，2-50字符）

- ✅ **用户体验优化**
  - 实时表单验证反馈
  - 加载状态提示
  - 成功/失败消息提示
  - 密码可见性切换
  - 响应式设计（适配手机/平板/电脑）

- ✅ **自动功能**
  - 注册成功后自动保存Token
  - 自动为新用户创建默认生命树
  - 1秒后自动跳转到仪表板

#### 表单字段

| 字段 | 必填 | 验证规则 | 说明 |
|------|------|----------|------|
| 邮箱 | ✅ | 有效邮箱格式 | 用于登录 |
| 昵称 | ❌ | 2-50字符 | 显示名称 |
| 密码 | ✅ | 8+字符，大小写+数字 | 账户密码 |
| 确认密码 | ✅ | 与密码一致 | 确认输入 |

#### 错误处理

```javascript
// 邮箱已存在
{
  "error": "该邮箱已被注册",
  "code": "EMAIL_EXISTS"
}

// 密码强度不足
{
  "error": "密码必须包含大小写字母和数字",
  "code": "WEAK_PASSWORD"
}
```

- ✅ **用户信息展示**

  - 加载状态提示

- ✅ **退出登录**
  - 清除Token和用户信息
  - 跳转回首页

#### 访问控制

```typescript
// 自动检查登录状态
useEffect(() => {
  const token = localStorage.getItem('token')
  if (!token) {
    router.push('/login')  // 未登录跳转
    return
  }
  fetchUserInfo(token)  // 获取用户信息
}, [])
```

## 🔄 用户流程

### 新用户注册流程
```
1. 访问首页 (/)
   ↓
2. 点击"立即注册"按钮
   ↓
3. 填写注册表单 (/register)
   - 输入邮箱
   - 输入昵称（可选）
   - 设置密码
   - 确认密码
   ↓
4. 点击"注册"按钮
   ↓
5. 后端处理：
   - 验证数据
   - 加密密码
   - 创建用户
   - 创建默认生命树
   - 生成Token
   ↓
6. 前端处理：
   - 保存Token到localStorage
   - 保存用户信息
   - 显示成功消息
   ↓
7. 自动跳转到仪表板 (/dashboard)
```

### 老用户登录流程
```
1. 访问首页 (/)
   ↓
2. 点击"登录"按钮
   ↓
3. 填写登录表单 (/login)
   - 输入邮箱
   - 输入密码
   - （可选）勾选"记住我"
   ↓
4. 点击"登录"按钮
   （或点击"使用测试账号"快速填充）
   ↓
5. 后端验证：
   - 检查邮箱是否存在
   - 验证密码是否正确
   - 生成Token
   ↓
6. 前端处理：
   - 保存Token
   - 保存用户信息
   - 显示成功消息
   ↓
7. 跳转到仪表板 (/dashboard)
```

## 💾 数据存储

### LocalStorage 结构

```javascript
// 存储的数据
localStorage.setItem('token', 'eyJhbGciOiJIUzI1NiIs...')
localStorage.setItem('user', JSON.stringify({
  id: 'cmgg6m06d0000avz389stnj83',
  email: 'zhangsan@lifetree.com',
  name: '张三',
  createdAt: '2025-10-07T06:31:30.661Z'
}))

// 读取数据
const token = localStorage.getItem('token')
const user = JSON.parse(localStorage.getItem('user') || '{}')

// 清除数据（退出登录）
localStorage.removeItem('token')
localStorage.removeItem('user')
```

## 🔒 安全性

### 密码安全
- ✅ 前端验证密码强度
- ✅ 后端使用bcrypt加密（salt rounds = 10）
- ✅ 密码不以明文传输
- ✅ 数据库只存储加密后的密码

### Token安全
- ✅ JWT Token有效期7天
- ✅ Token包含用户ID和邮箱
- ✅ 每次API请求验证Token
- ✅ Token验证失败自动清除

### 数据隔离
- ✅ 用户只能访问自己的数据
- ✅ API层验证Token中的用户ID
- ✅ 数据库查询自动过滤用户ID
