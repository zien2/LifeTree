### LifeTree 后端/全栈项目面试问答（可直接使用）

#### 1. 鉴权与安全：为什么前端不校验 JWT？
- **回答要点**：JWT 秘钥仅应在服务端；前端只检测 token 是否存在用于 UI 态，不做签名校验。API 读取 `Authorization: Bearer <token>` 服务端验证并解析用户身份。这样避免泄露 `JWT_SECRET`，同时让权限判断集中、可审计。

#### 2. 中间件如何避免“未登录 API 导致重定向循环”？
- **做法**：API 路径未鉴权直接返回 401 JSON，不发起 302/307 跳转；页面路由再由前端根据本地 token 控制跳转到登录页，彻底消除循环重定向。

#### 3. Prisma 与 MySQL 的 Schema 变更如何上线？
- **流程**：本地/CI 校验 schema → `prisma db push`（或 migrate）同步结构 → 生成 Prisma Client。上线时严禁对生产直接 destructive 变更，建议用 migrate 脚本评估与回滚方案。

#### 4. 计划数据的“统计口径”如何一处定义处处生效？
- **问题**：`dueDate` 与 `createdAt` 混用会导致不同页面统计不一致。
- **方案**：在 `lib/planUtils.ts` 抽象统一的筛选/排序方法（如今日=createdAt），所有页面/接口统一使用，避免散落代码造成偏差。

#### 5. 邮件验证怎样确保“未验证不可登录”？
- **做法**：注册成功生成邮箱验证 token，发邮件链接；登录接口在校验账号密码之后，额外检查 `emailVerified` 字段；未验证直接拒绝并提示重发验证邮件。验证链接使用 `NEXT_PUBLIC_BASE_URL` 动态拼接，兼容部署域名。

#### 6. 通知系统的投递与幂等？
- **策略**：计划类通知走即时顶栏展示、自动消退，不入持久化列表；系统类通知持久化并在铃铛中展示；
- **幂等**：以通知业务键（如计划ID+事件类型）去重，避免多次提交触发重复提醒。

#### 7. AI 分析服务调用的鲁棒性与降级？
- **实现**：后端统一封装 `/api/ai-analysis`；请求参数压缩、控制 `max_tokens`、30s 超时；捕获 `AbortError` 返回 408，前端提示可重试。失败时前端不影响核心功能，仅降级为“无 AI 建议”。

#### 8. Puppeteer 每日快照有哪些线上坑？
- **依赖**：Chromium/字体缺失、无沙箱权限（--no-sandbox）
- **登录**：建议改为“内部受保护截图 API + 内部 token”，定时任务直接请求 API，避免模拟用户态。
- **稳定**：等待 Canvas 稳定（可注入 `window.__TREE_READY__` 信号）后再截图，减少空白图。

#### 9. API 设计：返回结构与错误码规范？
- **规范**：统一 `{ success, data, message }`；错误使用 HTTP 状态码（401/403/422/500）；避免返回 HTML 错页，确保前端可解析并显示可读信息。

#### 10. 性能：如何减少不必要的数据库压力？
- **措施**：
  - 尽量批量获取（一次拉取 plans 到前端，局部在前端计算聚合）；
  - 读多写少的字段可做轻量缓存（如用户配置）;
  - 建议为高频筛选列（userId、createdAt、priority、status）建索引。

#### 11. 日志与可观测性怎么做？
- **做法**：API 入参摘要（脱敏）+ 关键路径日志；错误统一捕获并记录（含 requestId）；前端埋点页面白屏/接口超时。生产建议接入 Sentry/Elk。

#### 12. CI/CD 与分支保护如何配合？
- **CI**：Actions 跑安装、Prisma generate、Lint、Build；
- **保护**：`main` 需 PR 且至少 1 审核，必要时将 CI Job 名加入必需状态检查；
- **发布**：Docker 镜像构建与 Compose 启动，环境变量从 Secrets 注入。

#### 13. 环境变量与敏感信息治理？
- **策略**：`.env` 不入库，提供 `env.sample`；Secrets 存放在部署平台（GitHub/Git 服务/服务器 Secret 管理）；代码层避免打印明文密钥。

#### 14. 服务器部署时数据库迁移与回滚怎么做？
- **建议**：采用 Prisma Migrate，保持版本化；上线前在影子库演练；提供回滚脚本；关键数据表更新加维护窗口与备份。

#### 15. 常见线上问题排查清单
- 500 但返回 HTML：检查 `_document.tsx`、API try/catch、日志；
- 身份丢失：确认 Authorization 头、时区、token 过期；
- 构建失败：检查 Node 版本、Prisma schema、缺失 ENV；
- Puppeteer 错误：缺依赖或权限，尝试无沙箱与字体安装。
