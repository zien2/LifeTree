# 数据分析中心功能说明

## 新增功能

### 1. Excel导出功能 📊

**功能描述**：将用户的所有计划数据导出为Excel表格，便于离线分析和存档。

**使用方法**：
1. 进入 `/dashboard/analytics` 页面
2. 点击右上角的"导出Excel"按钮
3. 系统会自动下载包含所有计划数据的Excel文件

**导出内容**：
- 计划ID
- 标题
- 描述
- 状态（已完成/进行中）
- 优先级（高/中/低）
- 创建时间
- 截止时间
- 完成时间

**文件格式**：
- 文件名：`计划数据导出_YYYY-MM-DD_HH-mm-ss.xlsx`
- 格式：Excel (.xlsx)
- 编码：UTF-8

### 2. AI智能分析功能 🤖

**功能描述**：使用内置AI服务分析用户的计划完成情况，提供专业的优化建议。

**使用方法**：
1. 进入 `/dashboard/analytics` 页面
2. 点击右上角的"AI分析"按钮
3. 在弹出的对话框中点击"开始分析"按钮
4. 等待AI分析完成，查看分析结果

**分析维度**：
- **完成度评估**：评估当前完成率是否合理
- **优先级管理**：分析优先级分配是否合理
- **时间管理**：识别计划数量是否合适
- **效率优化**：基于数据模式提供改进建议
- **行动计划**：给出3-5个可执行的优化建议

**技术实现**：
- 使用内置AI API服务
- 无需用户输入API Key
- 分析结果控制在500-800字
- 支持中文分析报告

**安全说明**：
- 所有数据传输都经过加密
- 用户数据仅用于分析，不会被存储
- 分析过程完全自动化

## 技术实现

### Excel导出
- 使用 `xlsx` 库生成Excel文件
- 支持中文字符
- 自动设置列宽
- 客户端直接下载

### AI分析
- 后端API：`/api/ai-analysis`
- 调用内置AI服务
- 结构化数据传递给AI
- 返回格式化的分析结果

## 使用建议

1. **定期导出**：建议每周或每月导出一次数据，用于长期趋势分析
2. **AI分析**：建议在完成一定数量的计划后进行AI分析，获得更准确的建议
3. **API Key管理**：请妥善保管您的OpenAI API Key，不要分享给他人

## 注意事项

- Excel导出功能不需要额外的API Key
- AI分析功能使用内置服务，无需用户配置
- 如果AI分析失败，请稍后重试或联系管理员
- 分析结果仅供参考，请结合个人实际情况进行调整

## 环境配置

如需配置自定义AI服务，请在环境变量中设置：

```bash
# AI API配置
AI_API_URL="https://your-ai-api.com/analyze"
AI_API_KEY="your-ai-api-key"
```
