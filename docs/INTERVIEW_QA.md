### LifeTree 前端项目面试问答（可直接使用）

#### 1. 为什么选择 Next.js？CSR/SSR/SSG 如何取舍？
- **回答要点**：项目主要是登录后用户私有数据与强交互页面，采用 CSR 为主以提升体验；公共页面或需要 SEO 的部分可用 SSR/SSG；API 使用 Next.js API Routes，前后端一体化便于快速交付。

#### 2. 深色主题在 Ant Design 上如何做到“全局一致”？
- **难点**：AntD 组件（尤其 Modal/Dropdown）内部有多层结构与样式优先级，容易出现白边/白底。
- **做法**：
  - 局部组件优先使用 `styles`/`style` 精准覆盖；
  - 无法覆盖处使用全局 `.ant-` 选择器（如 `.ant-modal-content/header/body/footer`）统一深色与边框；
  - 必要时 `!important`，避免默认主题反复覆盖。

#### 3. Dashboard 卡顿如何优化？
- **问题**：日期范围改变导致图表与指标频繁重算与重渲染。
- **优化**：
  - 仅初始化拉取一次 `plans`；
  - `dailyData`、`stats`、`chartData`、`priorityData` 使用 `useMemo`；
  - 日期范围加入 300ms 防抖；
  - 后续可做图表组件动态 import 与可见时加载。

#### 4. “今日计划”口径如何统一？
- **背景**：曾用 `dueDate` 导致口径不一致。
- **方案**：统一以 `createdAt` 作为“今日”口径，并在 `planUtils` 中复用筛选逻辑，Dashboard、日历、今日抽屉共享，避免分叉实现。

#### 5. AntD 年视图为什么难改？如何兼顾稳定与效果？
- **难点**：年视图 DOM 结构与类名版本差异大，强制修改网格列/高容易影响月视图。
- **策略**：不强改布局，仅保证月格内“统计内容”完整显示（最小高度、溢出可视、内边距调整），减少选择器范围，避免互相污染。

#### 6. 生命树（Canvas）如何把计划映射为叶子并做动画？
- **映射**：对计划 `id` 做稳定哈希，分布到树的不同分支/位置；
- **状态**：新建→生长动画、完成→变绿、逾期未完成→变黄并可掉落；
- **性能**：减少层级与绘制次数，控制帧动画节奏，必要时分批更新。

#### 7. 每日快照如何自动保存？
- **实现**：Puppeteer 定时访问树页面，等待 Canvas 稳定后截图，按年/月/日归档；
- **坑**：服务器字体/Chromium 依赖、登录态；建议改为“服务端受保护截图 API + 内部 Token”规避登录。

#### 8. AI 分析为何最初很慢？如何提速？
- **问题**：提示词过长、`max_tokens` 偏大、无超时。
- **优化**：
  - 精简提示词：控制在 400–600 字建议；
  - 参数调优：`max_tokens↓`、`temperature=0.5`、`top_p/frequency/presence` 合理设置；
  - 30s 超时（AbortController）；
  - 初始分析结果作为聊天上下文首条，降低后续轮次开销。

#### 9. 为什么 JWT 只在服务端验证？
- **原因**：前端不应接触 `JWT_SECRET`，避免泄露；
- **做法**：前端仅存 token presence 控制 UI；服务端 API 读取 Authorization Bearer 进行校验与鉴权。

#### 10. 如何避免 API 鉴权导致的前端重定向循环？
- **做法**：中间件对未鉴权 API 返回 401 JSON，不做页面跳转；页面路由交由前端根据本地 token 决定跳转，消除循环。

#### 11. Drawer + Modal 的叠层与“防误关”如何处理？
- **做法**：通过 zIndex 确保 Modal 在上；当 Modal 打开时将 Drawer 的 `maskClosable=false`；关闭 Modal 后恢复，保证操作安全性。

#### 12. Excel 导出如何设计？
- **做法**：使用 `xlsx` 在客户端导出（ID、标题、状态、优先级、创建/截止/完成时间），避免占用后端资源；
- **注意**：时间统一用 dayjs 格式化，避免时区混乱。

#### 13. CI/CD 与分支策略怎么做？
- **CI**：GitHub Actions（Node 18/20、npm ci、Prisma generate、Lint、Build）；
- **保护**：`main` 分支保护 + 至少 1 次 Review；
- **部署**：Docker 化，Compose 一键启动；`.env` 提供示例模板，Secrets 放在平台层。

#### 14. 全局样式覆盖如何避免“牵一发动全身”？
- **原则**：优先局部覆盖；全局覆盖时缩小选择器范围（仅目标组件面板）；避免影响其它模式（如月/年视图互相影响）；用注释标明“只对 X 生效”。

#### 15. 常见线上排查范式？
- **步骤**：
  - 明确错误层级（API/前端渲染/构建/路由/权限）
  - 统一错误返回 JSON，不吞栈；
  - 增加临时日志（含关键 env、token 是否存在但不泄露敏感值）；
  - 文档化排查过程（`DEBUGGING_LOG.md`）。
